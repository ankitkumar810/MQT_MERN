# Frontend Training 🚀

This repository contains a collection of beginner-friendly web development projects created while learning HTML, CSS, JavaScript, Git, and GitHub.

## Projects

### 1. CSS_Marquee_TrainX
A marquee animation project built using pure CSS to understand animations and keyframes.

### 2. HTML_Marquee_TrainX
A simple scrolling text project demonstrating basic HTML structure and marquee-style effects.

### 3. JavaScript_Marquee_TrainX
An interactive marquee project powered by JavaScript with dynamic controls and animations.

### 4. Git and GitHub
Practice exercises, notes, and examples covering Git fundamentals, version control, and GitHub workflows.

### 5. NGO Website
A responsive NGO website showcasing organization details, programs, and contact information.
